# 言い返しシミュレーター 💬⚡

現実では言い返せないアンチコメントに、思いっきり言い返せるWebゲーム。
架空のSNS「Chirpy」に投稿 → アンチコメントが付く → 言い返す → AIの審判が採点して、うまく返せたら **NICE REPLY!** の演出が出ます。

## 遊び方

1. [Google AI Studio](https://aistudio.google.com/apikey) で Gemini APIキーを無料で発行する
2. ページを開いてAPIキーを貼り付ける（キーはブラウザの localStorage にだけ保存されます）
3. 相手のレベル（Lv1〜5）と投稿内容を選んで「投稿してスタート」
4. アンチに返信。**論破ゲージ**を右端まで押し込めば勝ち、左端まで押し込まれたら負け。10ターンで決着しなければ判定。

| 判定 | 演出 |
| --- | --- |
| CRITICAL REPLY!! | 金色のフラッシュ＋紙吹雪、いいね・RTが大量に付く |
| NICE REPLY! | 緑のフラッシュ＋紙吹雪 |
| 微妙… | 灰色、小さく揺れる |
| BAD REPLY… | 赤いフラッシュ＋画面にヒビ、大きく揺れる。アンチのコメントにいいねが付く |
| 炎上!! | 人格攻撃・差別・脅迫などをすると、あなたの返信が晒されて炎上 |

うまい返しを連続すると COMBO ボーナスでゲージが大きく動きます。

### レベル

| Lv | 相手 | 特徴 |
| --- | --- | --- |
| 1 | かまってちゃん | 語彙も論理もない。採点も甘め |
| 2 | 通りすがり | 上から目線の浅い一般論 |
| 3 | 自称正論マン | それっぽい理屈で攻めてくる |
| 4 | 冷笑系インフルエンサー | 皮肉・揚げ足・「効いてて草」 |
| 5 | レスバ最強の論破王 | 一切動揺せず、詭弁も駆使。採点は非常に厳しく、うまい返しでもゲージは少ししか動かず、失敗すると大きく押し込まれる |

## GitHub Pages での公開

ビルド不要の静的サイトです（`index.html` / `style.css` / `app.js`）。

1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを公開したいブランチ、フォルダを `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/anti_comment/` で公開されます

## Gemini API について

- 無料枠で遊べます（クレジットカード不要）。ただし1分・1日あたりの回数制限があり、上限はモデルごと・時期によって変わります。1ターン＝1リクエストです。
- 429エラー（回数制限）が出たら、設定画面の「モデル設定」で別のモデル（例：`gemini-flash-lite-latest`）に切り替えると続けられることがあります。
- 無料枠では送信した内容がGoogleのサービス改善に使われる場合があります。個人情報は書かないでください。
- GitHub Pages は静的ホスティングなので、APIキーをコードに埋め込むと誰でも見えてしまいます。そのため、このアプリでは**遊ぶ人それぞれが自分のキーを入力する**方式にしています。
